# Требования безопасности

1. Данные с датчиков и камер передаются компании-партнёру по защищенному каналу с использованием TLS
2. Результаты работы алгоритмов Партнёра передаются в нашу систему через DMZ + ACL с использованием доверенных сертификатов. Сертификаты обновляются раз в N месяцев
3. Хранение данных у Партнёра соответсвуют всем необходимым критериям безопасности. Никакой персональной информации о клиентах не сохраняется. Для информации об авто (номер машины) и адресе (для домофона) использовать псевонимизацию. Вести политику удаления данных после использования.
4. Использование аутентификации и авторизации с применением Zero Trust и принципом наименьших привилегий
